# Palíndromo em Java


Projetinho que fiz pra treinar manipulação de String em Java. A ideia é simples: o programa recebe uma palavra e verifica se ela é um palíndromo, comparando os caracteres do começo com os do final.

## Como funciona

O usuário digita uma palavra, e o programa percorre ela caractere por caractere, comparando a primeira letra com a última, a segunda com a penúltima, e assim por diante. Se todas baterem, é palíndromo.

## O que é um palíndromo?

Palavra que se lê igual de trás pra frente. Tipo:

- arara
- ovo
- osso
- radar

Já "casa" ou "java" não contam, porque invertendo muda tudo.

## Tecnologias usadas

- Java
- IntelliJ IDEA

## Conceitos que pratiquei

- Scanner pra entrada de dados
- Laço for
- if/else
- Variável booleana
- charAt() e length()
- Comparação de caracteres

## Motivação

Fiz esse projeto pra fixar melhor manipulação de string em Java, principalmente os métodos charAt() e length(), e também pra treinar lógica com laços e condicionais.
